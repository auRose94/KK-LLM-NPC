# Localization (L10N) — translating KKLLMNPC

The mod follows **KoboldKare's own language setting**: pick a language in the
game's options and the mod's user-facing text follows it. Ships with English
(complete), German (complete), and partial seeds for French, Spanish,
Portuguese (BR), Russian, Japanese and Simplified Chinese — every missing
string falls back to English automatically, so partial files are always safe.

## What gets translated vs. what stays English

| Surface | Localized? | Why |
|---|---|---|
| In-game options tabs + setting labels | ✅ | the player reads these |
| Spectate HUD (inside-eater line, struggle bar) | ✅ | the player reads this |
| **The kobolds' SPOKEN language** | ✅ via `[LLM] Language` | prompt steering — see below |
| Perception keys, world events, console output, prompts | ❌ | this is the LLM's *protocol* — English is the protocol, and translating it would degrade every model; the SPEECH language is what `[LLM] Language` is for |
| Config descriptions (this file's siblings) | ❌ | developer documentation |
| Log lines | ❌ | for bug reports |

## Translation files

Location: `BepInEx/plugins/KKLLMNPC/lang/<code>.json` — plain flat JSON,
one file per locale code (`de.json`, `pt-BR.json`, `zh-hans.json`, …).

**Keys ARE the English strings.** A file maps English text → translated text:

```json
{
  "Temperature": "Temperatur",
  "you are inside {0} — watching": "du bist in {0} — Zuschauen"
}
```

- Missing key → English (identity fallback). Missing file → English. A file
  with ONE key is a valid contribution.
- `en.json` is written automatically on first boot as the complete template —
  copy it, rename it to your locale, translate the values (never the keys).
- `{0}` / `{1}` are placeholders — keep them (order can change to fit your
  grammar: `{1}` before `{0}` is fine).
- Nested objects are flattened with a dot: `{"hud": {"inside": "…"}}` → the
  key `hud.inside` — useful for grouping, not required.
- The mod reloads the files at startup only. Edits need a game restart.
- Never re-save with a tool that escapes non-ASCII (`\uXXXX` is fine, but
  readable UTF-8 is preferred); the parser accepts both.

Contributing: PRs to the repo's `lang/` directory, one file per locale.

## The kobolds' spoken language — `[LLM] Language`

`auto` (default): the model matches whatever language the humans use. Any
other value (`German`, `Portuguese`, `日本語`, `pt-BR`, …) becomes a hard
directive appended to every persona (act mode AND console): **all chat lines
(say/echo) must be written in that language**, while the command protocol and
perception stay English and proper nouns stay unchanged.

This is prompt steering — small local models may drift back to English on
long sessions; a stronger instruct model follows it well. The perception
text itself is never translated, by design: the model reads English, speaks
your language.

## Options-menu labels under the hood

The in-game options tabs inject their labels into the game's own Unity
Localization table (one runtime entry per string, values added for **every**
locale the game ships — translated where a lang file provides one, English
otherwise). Switching the game's language re-renders the tab through the
game's normal `LocalizeStringEvent` machinery — no mod-specific language
picker, no duplication of Unity Localization.
